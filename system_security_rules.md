# Security Protocols & Operational Rules

## 1. Sandbox Isolation Rules (`MANTITUP`)

* **R01 - Ephemeral Lifecycle:** Every microVM instance MUST be destroyed immediately upon task execution finish or timeout. No state shall persist between PR evaluations.
* **R02 - Strict Network Egress Control:** MicroVM network interfaces MUST route through an egress proxy that logs all DNS queries and restricts outbound connections to unauthorized IP address ranges.
* **R03 - Resource Capping:** Each Firecracker microVM MUST be restricted to a maximum of 2 vCPUs, 1GB RAM, and 5GB ephemeral disk space to mitigate Denial of Service (DoS) attacks.

---

## 2. Telemetry & Observation Rules (`OSEN` & `TRACECOMMON`)

* **R04 - Kernel Trace Coverage:** eBPF probes MUST intercept all `execve`, `openat`, and `connect` system calls originated by untrusted processes.
* **R05 - Zero Data Leakage:** Honeypot keys must be synthetic and harmless. Real secrets MUST NEVER be injected into detonation environments.
* **R06 - Event Immutability:** Event streams generated by `OSEN` MUST be append-only and cryptographically signed prior to ingestion by `TRACECOMMON`.

---

## 3. AI Agent Remediation Rules (`ANAKIN`)

* **R07 - Human-in-the-Loop Option:** Automated patches generated by `ANAKIN` MUST be submitted as suggested commits or dedicated security branches—never merged directly into protected branches (`main`/`master`).
* **R08 - High Confidence Threshold:** Threat classifications MUST exceed an 85% confidence score from the agent before blocking a Pull Request build check.
